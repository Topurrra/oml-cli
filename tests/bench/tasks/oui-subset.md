## Task (identical for every agent)
In the OutSystems 11 Reactive module, build a small design system called **OUI**: the 11 Reactive blocks below and one page template screen that uses them. Put every block and the screen in a UI flow named `UI` (create it if it does not exist). The module has no theme of its own: create a theme `BenchTheme`, make it the module's default theme and put the shared CSS in it.

Write everything yourself in plain CSS and vanilla JavaScript (no React, no libraries, no CDN, no downloads, no web fonts). Use the exact block, input, event and placeholder names given, because the result is compared element by element with a reference. "Placeholder X" means the block has a placeholder named X. Inputs are optional unless marked mandatory; give each the default shown. Scope CSS under one root class per block with the prefix `oui-` (for example `oui-btn`). Define the colours as CSS variables on `:root` for a light theme and again under `html[data-theme="dark"]` for a dark theme, and use only those variables in the blocks. Any JavaScript runs from the block itself, touches only its own elements and respects `prefers-reduced-motion`. Icons are named by text (for example `user`, `chart`, `star`, `chevron-left`, `check`): draw the few names this task uses as small inline SVGs and show nothing for an unknown name.

Blocks:
1. OuiDivider: a thin horizontal line between sections. Inputs: Label (Text, default ""): when not empty, the text sits in the middle of the line.
2. OuiButton: a button whose label is in placeholder Label. Inputs: Variant (Text, default "primary"; primary, secondary, outline, ghost, danger or link), Size (Text, default "md"; sm, md or lg), Icon (Text, default ""; an icon shown before the label), IsLoading (Boolean; shows a spinner and ignores clicks), IsDisabled (Boolean), IsFullWidth (Boolean; the button fills its row). Event: OnClick(), fired on click unless disabled or loading.
3. OuiAlert: a message box. Inputs: Tone (Text, default "info"; neutral, info, success, warning or danger, each with its own colour and icon), Title (Text, default ""), Description (Text, default ""; secondary text under the title), IsDismissible (Boolean; shows a close button). Closing hides the alert (the block keeps that state itself) and fires event OnDismiss(). Placeholder Actions: optional buttons under the text.
4. OuiField: the frame around one form input. Inputs: Label (Text, mandatory), Hint (Text, default ""; help text under the input), ErrorMessage (Text, default ""; when not empty it is shown in the danger colour instead of the hint and the field looks invalid), IsRequired (Boolean; a required mark after the label). Placeholder Input: the Input, Dropdown, TextArea or another block that the screen puts there.
5. OuiChoice: label and description next to a Checkbox, Switch or RadioButton. Inputs: Label (Text, mandatory), Description (Text, default ""), ControlAtEnd (Boolean; the control goes to the right end of the row, for switches). Placeholder Control: the widget. The screen gives that widget the class `oui-check`, `oui-switch` or `oui-radio`; style those three classes so a checkbox, a switch and a radio look like part of OUI.
6. OuiSelectWrap: adds a chevron to a Dropdown widget that has the class `oui-select`, and styles it like the other inputs. No inputs. Placeholder Content: the Dropdown.
7. OuiNumberField: a number Input with a minus button before it and a plus button after it. Placeholder Input: the screen's Input (type Number) bound to the screen's own variable. Inputs: Step (Decimal, default 1), Min (Decimal, default 0), Max (Decimal, default 0; 0 means no upper limit), Suffix (Text, default ""; a unit shown after the value), Size (Text, default "md"; sm, md or lg), HasError (Boolean; the danger border). The buttons change the value by Step within Min and Max, and the screen variable bound to that Input must change with them.
8. OuiRadioCards: up to four large choices as cards, one selectable. Inputs: Title1 to Title4, Description1 to Description4, Icon1 to Icon4 (all Text, default ""; a card shows only when its title is not empty), Value (Text, default ""; the title of the selected card). Event: OnChange(Value: Text), fired with the picked title when the user picks a card with the mouse or the keyboard. Screen readers must hear it as a radio group.
9. OuiStepper: progress through up to five steps in a row with a line between them. Inputs: Step1 to Step5 (Text, default ""; a step shows only when its title is not empty), Current (Integer, default 1). Steps before Current show as done with a check mark, Current is highlighted, later steps are pending.
10. OuiThemeToggle: a round icon button with a sun in dark mode and a moon in light mode. Inputs: Size (Text, default "md"). A click switches `data-theme` on `<html>` between light and dark, with a circular reveal from the button where the browser supports it (none with reduced motion). The choice is saved in localStorage; with no saved choice, the theme follows `prefers-color-scheme`.
11. OuiLayoutBlank: a layout block for simple pages (sign-in, error, forms): the app name on top, a centred card with the title and the main content, and a footer below the card. Inputs: AppName (Text, default "OUI"), Width (Integer, default 420; the card's maximum width in pixels), ShowThemeToggle (Boolean, default True; shows an OuiThemeToggle at the top). Placeholders Title, MainContent and Footer. Screens use it as their layout.

Screen `OuiTplWizard` (UI flow `UI`, layout block `OuiLayoutBlank` with AppName "Northwind" and Width 640, title "Open a business account" in the Title placeholder, access: registered users only; do not change the module's default screen): a form in four steps that opens a business account.
- A structure `OuiTplOption` with one Text attribute `Label`. On initialize, fill a local list of it with Portugal, Georgia, Germany, France, Italy and Japan.
- At the top an OuiStepper with the steps Company, Contact, Plan and Review; Current is the step the user is on.
- Under it a danger OuiAlert "Check the marked fields" / "Correct them to continue.", shown only after Continue found errors on the current step.
- Step 1, Company: Company name (required; error when empty or shorter than 3 characters), Registration number (required, hint "As shown on your registration certificate."; error when empty or shorter than 6 characters), Country (required; a Dropdown of the countries in an OuiSelectWrap, default Portugal), Website (hint "Optional.").
- Step 2, Contact: Contact name (required), Work email (required; error when empty or when it is not an address like name@company.com), Phone (hint "Optional.").
- Step 3, Plan: an OuiRadioCards with Starter ("EUR 9 per seat. Payments and statements.", icon user), Business ("EUR 19 per seat. Approvals and roles.", icon chart) and Enterprise ("EUR 39 per seat. A personal manager.", icon star), default Business; Seats in an OuiField with an OuiNumberField (Min 1, Max 250, default 5; error outside 1 to 250); a Switch "Pay yearly" with the description "Save 20% on every seat." in an OuiChoice with the control at the end (default on); and an OuiField "Terms" (required) with a Checkbox "I accept the terms and the privacy policy" in an OuiChoice (error when not checked).
- Step 4, Review: the answers in three groups (Company, Contact, Plan), each with a small link-style OuiButton "Edit" that goes back to that step, OuiDividers between the groups, "Not given" for empty optional fields, and the price per month: seat price x Seats, minus 20% when yearly, as "EUR 1,234.56".
- Every input is in an OuiField with its label, and every error is shown in that field's ErrorMessage.
- At the bottom a ghost OuiButton "Back" with the icon chevron-left (hidden on step 1) and a primary OuiButton "Continue" ("Submit application" on step 4). Continue checks the fields of the current step and moves on only when they are valid. Submit shows the success state.
- Success state (instead of the stepper and the form): "Application submitted", the text "Your reference is NW-204815. We will write to <email> within two working days." and a secondary OuiButton "Open another account" that clears the form and goes back to step 1.
- In the Footer placeholder: the text "Back to the dashboard" (plain text; there is no dashboard screen).

Done when: the module has zero validation errors, the 11 blocks, the structure and the screen exist, and you report: every tool call that failed and why, and anything you could not build.
